# val-emotes-data

Free companion resource for **val-emotes**: custom animations and props, plus
the animal emote compatibility table.

## Install

1. Download this repository and place the folder in your `resources` as
   `val-emotes-data`.
2. In `server.cfg`, start it before val-emotes:
   ```
   ensure val-emotes-data
   ensure val-emotes
   ```
